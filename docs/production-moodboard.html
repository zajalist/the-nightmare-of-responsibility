Main style · photoreal grey, inked, smoking

A mix of three moods. C is the base: a believable black-and-white photograph of a grandparent's house. A inks it with hard graphic contrast. D lets dark sand and smoke curl off the Nightmare and out of the corners.

C · Photoreal black and white

Built

Lux3D PBR meshes under real lights, turned grey and split-toned by M_PP_DreamMono. Albedo keeps its real hue, because the payoff bursts reveal it.

A · Inked contrast

NextMedEstablished

Crushed blacks, hard hatched shadows, bold ink edges, all from one post-process pass. Edges come from a Sobel filter on SceneDepth and WorldNormal. Hatching samples a 128² hatch texture (three densities in RGB, 8 KB) projected on the world position the pass rebuilds from depth, so the lines stick to surfaces. A levels curve crushes the blacks before the split tone. Gate the extras with a Quality Switch node. Verify the cost on a 1050 Ti and whether edges stay stable under TAA upsampling.

D · Smoke-and-sand tendrils

NextLowOur idea

Lux3D splat meshes with a looping drift in the material (section 3). Each tendril is a static mesh that never simulates, so it costs one draw call and no CPU.

1 · UI concepts

Screen-space UMG draws after the post process, so the dream's grey never touches it. The UI has to hold the palette by itself: soot and bone, tungsten for anything you can act on, burst colors only inside a payoff.

Ship route · UI material

EstablishedLow
Build
WBP_SandButton is a Button plus an Image using M_UI_SandButton (Material Domain: User Interface). Hover, Press and Seed scalars go through Get Dynamic Material → Set Scalar Parameter Value, eased by a short UMG animation.
Rest
A rounded-rect mask computed from UVs, a 128² grain texture panning slowly, a rim light on the top edge.
Hover
A panning noise band streams grains along the top edge. A 256×64 drip strip pans down from the bottom edge, gated by Hover.
Press
Noise-threshold dissolve with a glinting edge, Press 0 → 1 → 0 in 0.6 s. The click fires immediately, so the animation never delays the action.
Label
Wrap the button in a Retainer Box using the same dissolve as its effect material, and the text dissolves with the sand. A Retainer Box renders its children to a render target, so use it only on the few buttons on screen.

2 · Dream cinematic effects

All of them run on the same third-person test shot so they can be compared. A post-process material can't read the previous frame, so anything with memory needs a render-target ping-pong or a C++ pass. Every card lists the cheap version we ship first.

3 · Sand and smoke · splat meshes

No Niagara. Smoke and sand are Lux3D Gaussian splats baked into one static mesh per effect and animated entirely in its material. Everything else uses cheap material tricks: dissolve, World Position Offset, panning textures, depth fade and fresnel.

ChannelHolds
PositionThe splat center. All four corners share it.
UV0Corner, −1 to 1. WPO expands it to face the camera.
UV1Radius (3σ of the largest scale) and a random seed.
Vertex colorRGB from the PLY's DC term, A from its opacity.
UV2–UV6The nine degree-1 spherical harmonic coefficients, plus one spare.
Morph meshesTarget position B goes in UV2–UV3 and SH is dropped, to stay inside Unreal's 8 UV channels.

M_SplatMesh

NextOur ideaMed
Billboard
WPO adds the corner times the radius, transformed from view space to world space.
Falloff
Opacity × exp(−4.5 r²) through DitherTemporalAA into Opacity Mask, Blend Mode Masked. No sorting and any draw order; TAA or TSR resolves the dither, while FXAA leaves it grainy.
Color
DC plus 0.4886 × (−y·c₁ + z·c₂ − x·c₃) per channel, using the view direction in the PLY's frame Verify Lux3D's axis convention.
Motion
A splat shows while its seed sits between Dissolve and Reveal (Custom Primitive Data). Once dissolved, WPO adds gravity × (Dissolve − seed)² and a panning-noise sway. Tendrils loop with frac(Time × rate + seed).
Setup
Cast Shadow off, Bounds Scale raised so drifting splats aren't culled, Use Full Precision UVs off (half floats are plenty), velocity output for WPO on so TAA doesn't smear Verify the 5.8 setting name.
Budget
40k splats per hero effect: 160k vertices, 80k triangles, one draw call, about 9 MB of vertex data with SH (6 MB without) before pak compression. Low draws a 20k LOD, which is just the first half of the seed-shuffled splats.

Why it's cheap and where it isn't. One mesh, one material, zero CPU per splat. The cost is overdraw: a masked quad runs its pixel shader until depth rejects it, so the bake keeps quads tight at 3σ and drops splats below 1/255 opacity. Target 1.5 ms per hero effect at 720p on a 1050 Ti Verify on target hardware.

Firm now

  • One shader format, no static lighting, no Nanite. Fewer permutations means a smaller build and one render path.
  • Lumen, virtual shadow maps and volumetric fog are off on Low, with the fallbacks above already art-directed.
  • No Niagara. Sand and smoke are splat meshes with one draw call each.
  • Texture caps per asset class and a procedural house shell.
  • 30 fps cap on Low, and the Dream effects setting on every effect.

Verify on target hardware

  • Engine and shader size: package the empty project on day 1.
  • Ink pass and TSR cost on the 1050 Ti at 720p internal.
  • Splat overdraw on the Iris Xe, and how far the 20k LOD carries.
  • Time-shift layer 1: the half-res capture cost during dream beats.
  • Lux3D output: texture resolution, triangle counts and the PLY axis convention at import.
  • First-run shader hitches with a cleared driver cache.
